# DVD Logo Animation

- Written in C using [Raylib](https://www.raylib.com/).
- This example can work with low FPS (big delta time)

https://github.com/user-attachments/assets/0185f2bf-e0a8-4b1a-8274-ac5cffced21f

# Quick Start

- You must have `raylib` installed system-wide or you can change cflags/ldflags in Makefile
- Run `make` to build `main.c`
- Run `./main` to run program
